# Data

`catalog254.json` and `catalog254.csv` contain the full 254-entry catalog.

Fields: `id`, `level`, `expression`, `unit`, `l`, `t`, `r`, `v`, `wb`, `gr`, `kind`, `tensor`, `status`, `source`, `note`.

- 16 level-1 units.
- 52 R4 GET.
- 60 R5 S,T,Fi.
- 18 R6 T,F,Fi.
- 36 R7 S,F,Fi.
- 72 R8 S,T,F,Fi.

`catalog50.json` / `catalog50.csv` are the legacy 50-entry subset, kept for reference.
