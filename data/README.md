# Data

`catalog50.json` and `catalog50.csv` contain the 50-entry prototype.

Fields: `id`, `level`, `expression`, `unit`, `l`, `t`, `r`, `v`, `wb`, `gr`, `kind`, `tensor`, `status`, `source`, `note`.

- 16 level-1 units.
- 14 GET standard/label.
- 10 R5 standard/bridge.
- 10 phase candidates (R6–R8).
