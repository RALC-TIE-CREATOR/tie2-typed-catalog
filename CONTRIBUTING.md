# Contributing

This is a research prototype. Before opening a PR:

1. Keep the dimensional rules intact: no `T⁻²`, `L⁴`, `R²`, or self-powers.
2. Add a test in `TIE2/Examples.lean` for any new rule.
3. Update `data/catalog50.json` and regenerate `TIE2/Catalog.lean`.
4. Run `lake build`.
